# Ausgabenmanager

**Autor:** [Dein Name]

## Projektbeschreibung

Der Ausgabenmanager ist ein Java-Konsolenprogramm, mit dem persönliche Ausgaben erfasst und übersichtlich verwaltet werden können. Zu jeder Ausgabe können ein Betrag, eine Kategorie, ein Datum und eine kurze Beschreibung gespeichert werden. Kategorien wie Lebensmittel, Freizeit oder Transport sollen durch unterschiedliche Farben leichter erkennbar sein.

Das Projekt wird im Rahmen des Unterrichts schrittweise entwickelt. Ziel ist es, die Grundlagen der strukturierten Programmierung in Java praktisch anzuwenden und dabei den Einsatz von generativer KI beim Programmieren kennenzulernen.

## Geplante Nutzung

Das Programm soll über ein Konsolenmenü bedient werden. Nutzerinnen und Nutzer können Ausgaben eingeben, gespeicherte Ausgaben ansehen und ihre Ausgaben zusammenrechnen lassen.

## Technische Vorgaben

- Umsetzung in Java als Konsolenprogramm
- Strukturierte Programmierung mit Methoden und übersichtlichem Ablauf
- Für Ausgaben dürfen Records oder einfache Klassen verwendet werden.
- Daten sollen mit Arrays gespeichert werden.
- Keine Abstraktionen, Vererbung, Collections oder sonstigen höheren Java-Features verwenden.
- Die Kategorien sollen farblich dargestellt werden, sofern dies in der Konsole unterstützt wird.
